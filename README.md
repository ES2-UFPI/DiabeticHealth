O **DiabeticHealth** é uma solução desenvolvida para auxiliar pacientes diabéticos no monitoramento diário de sua saúde. O foco do projeto é simplificar o registro de glicemia, alimentação e medicamentos, proporcionando uma visão clara da evolução do tratamento e facilitando o compartilhamento de dados com profissionais de saúde.

Este projeto foi desenvolvido como parte da disciplina de **Engenharia de Software II (ES2)** na **Universidade Federal do Piauí (UFPI)**.

## ✨ Funcionalidades Principais

- **Registro de Glicemia:** Entrada rápida de níveis de açúcar no sangue com tags (em jejum, pós-prandial, etc.).
- **Diário Alimentar:** Log de refeições para entender o impacto dos carboidratos na glicemia.
- **Controle de Insulina/Medicação:** Lembretes e registros de doses aplicadas.
- **Relatórios:** Gráficos de tendência e histórico exportável para consultas médicas.
- **Lembretes Inteligentes:** Notificações para medição e ingestão de medicamentos.
